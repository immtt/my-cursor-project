# 导入模板说明

## 系统建议数据（dataset_type=system）

必填列：

- 排线日期（YYYY-MM-DD）
- 运单号
- 归属线路
- 始发仓库
- 拼载门店（逗号分隔）
- **车辆类型**（如 4.2米标箱、4.2米高栏；系统与手工可填不同车型）
- 配送体积
- 装载率

建议附带列：

- 预计公里数
- 预计时效

## 手动排线数据（dataset_type=manual）

必填列：

- 排线日期（YYYY-MM-DD）
- 运单号
- 归属线路
- 始发仓库
- 拼载门店（逗号分隔）
- **车辆类型**（同上）
- 配送体积
- 装载率

说明：

- 手动数据中的里程、时效可留空，系统将在比对前自动补算。
- 前端「导出Excel」或接口 `GET /api/import-template` 下载的模板含 **「导入数据」+「填写说明」** 两个工作表，其中明确列出含 **车辆类型** 的必填项。
