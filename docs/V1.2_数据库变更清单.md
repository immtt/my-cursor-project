# V1.2 数据库变更清单

**目的**：支撑 V1.2 决议（软失效覆盖、结构化失败门店、最小审计能力）

---

## 1. 现有表改造

## 1.1 `sys_suggest`

新增字段：
- `batch_id` VARCHAR(64) NOT NULL：导入批次号
- `is_active` TINYINT NOT NULL DEFAULT 1：是否生效（1生效，0失效）
- `import_operator` VARCHAR(64) NULL：导入操作人
- `imported_at` DATETIME NULL：导入时间

新增索引建议：
- `idx_sys_date_type_active(route_date, is_active)`
- `idx_sys_batch(batch_id)`

**路线地图（与 PRD / 设计文档对齐）**

- `route_polyline` MEDIUMTEXT NULL：驾车路径规划得到的道路级折线（高德 polyline 编码或项目约定 JSON）；用于结果行地图展示，可与接口 `path` 解码结果同源。

## 1.2 `manual_route`

新增字段：
- `batch_id` VARCHAR(64) NOT NULL
- `is_active` TINYINT NOT NULL DEFAULT 1
- `import_operator` VARCHAR(64) NULL
- `imported_at` DATETIME NULL

新增索引建议：
- `idx_manual_date_active(route_date, is_active)`
- `idx_manual_batch(batch_id)`

**路线地图**

- `route_polyline` MEDIUMTEXT NULL：补算成功时与 `est_distance` / `est_duration` 一并写入，与地图轨迹同源。

## 1.3 `compare_result`

字段变更：
- `volume_diff_rate` -> `volume_diff`（DECIMAL(10,2) NULL）

新增字段：
- `match_score` DECIMAL(8,4) NOT NULL：原始匹配度（0~1）
- `run_batch_id` VARCHAR(64) NOT NULL：比对运行批次号

新增索引建议：
- `idx_compare_date_active(route_date)`
- `idx_compare_run_batch(run_batch_id)`

## 3. DDL 草案（MySQL）

```sql
ALTER TABLE sys_suggest
  ADD COLUMN batch_id VARCHAR(64) NOT NULL DEFAULT '',
  ADD COLUMN is_active TINYINT NOT NULL DEFAULT 1,
  ADD COLUMN import_operator VARCHAR(64) NULL,
  ADD COLUMN imported_at DATETIME NULL;

ALTER TABLE sys_suggest
  ADD INDEX idx_sys_date_type_active(route_date, is_active),
  ADD INDEX idx_sys_batch(batch_id);

ALTER TABLE manual_route
  ADD COLUMN batch_id VARCHAR(64) NOT NULL DEFAULT '',
  ADD COLUMN is_active TINYINT NOT NULL DEFAULT 1,
  ADD COLUMN import_operator VARCHAR(64) NULL,
  ADD COLUMN imported_at DATETIME NULL;

ALTER TABLE manual_route
  ADD INDEX idx_manual_date_active(route_date, is_active),
  ADD INDEX idx_manual_batch(batch_id);

ALTER TABLE compare_result
  CHANGE COLUMN volume_diff_rate volume_diff DECIMAL(10,2) NULL,
  ADD COLUMN match_score DECIMAL(8,4) NOT NULL DEFAULT 0,
  ADD COLUMN run_batch_id VARCHAR(64) NOT NULL DEFAULT '';

ALTER TABLE compare_result
  ADD INDEX idx_compare_date(route_date),
  ADD INDEX idx_compare_run_batch(run_batch_id);

CREATE TABLE IF NOT EXISTS import_audit_log (
  id BIGINT PRIMARY KEY AUTO_INCREMENT,
  batch_id VARCHAR(64) NOT NULL,
  dataset_type VARCHAR(16) NOT NULL,
  route_date DATE NOT NULL,
  operator VARCHAR(64) NULL,
  total_rows INT NOT NULL,
  success_rows INT NOT NULL,
  failed_rows INT NOT NULL,
  created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
  INDEX idx_import_audit_date(route_date),
  INDEX idx_import_audit_batch(batch_id)
);

CREATE TABLE IF NOT EXISTS compare_run_log (
  id BIGINT PRIMARY KEY AUTO_INCREMENT,
  run_batch_id VARCHAR(64) NOT NULL,
  route_date DATE NOT NULL,
  operator VARCHAR(64) NULL,
  duration_ms BIGINT NOT NULL,
  result_count INT NOT NULL,
  created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
  INDEX idx_compare_run_date(route_date),
  INDEX idx_compare_run_batch(run_batch_id)
);

CREATE TABLE IF NOT EXISTS gaode_calc_failure_log (
  id BIGINT PRIMARY KEY AUTO_INCREMENT,
  manual_id BIGINT NOT NULL,
  route_date DATE NOT NULL,
  failed_store VARCHAR(200) NOT NULL,
  reason VARCHAR(500) NOT NULL,
  retry_count INT NOT NULL DEFAULT 0,
  last_retry_at DATETIME NULL,
  created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
  INDEX idx_gaode_failure_date(route_date),
  INDEX idx_gaode_failure_manual(manual_id)
);
```
